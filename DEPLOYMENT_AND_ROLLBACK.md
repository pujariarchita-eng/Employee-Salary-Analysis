# Deployment and Rollback Evidence

## Project
Employee Salary Analysis – Veda Technology Task 3

## Deployment Configuration

This project is a Python-based Jupyter Notebook project for analyzing employee salary data.

The project does not require deployment to a web server or cloud platform because it is designed to run as a Jupyter Notebook or Google Colab notebook.

### Environment

- Python 3.x
- Jupyter Notebook / Google Colab
- Pandas

### Running the Project

1. Open Employee_Salary_Analysis_Task3.ipynb in Jupyter Notebook or Google Colab.
2. Make sure Python is available.
