# Employee Salary Analysis

## Veda Technology – AI & ML Track – Task 3

### Project Description

This project analyzes employee salary data using Python. The program calculates the total salary, average salary, highest salary, and lowest salary from a manually created employee salary dataset.

### Objective

The main objective of this project is to practice numerical data processing and basic data analysis using Python.

### Tools Used

- Python
- Jupyter Notebook
- Pandas

### Dataset

The project uses manually created employee salary data.
